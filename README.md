# Kurt Weddings – Tarifs

Pour mettre le site en ligne avec GitHub Pages :

1. Crée un dépôt sur github.com (par exemple `kurt-weddings`).
2. Clique sur **Add file → Upload files** et glisse **tout le contenu** de ce dossier : le fichier `index.html` ET le dossier `img`.
3. Clique sur **Commit changes**.
4. Va dans **Settings → Pages**, choisis **Branch : main** et le dossier **/ (root)**, puis **Save**.
5. Après une minute, le site est en ligne à `https://TON-PSEUDO.github.io/kurt-weddings/`.

Vidéos : sur Vimeo, pour chacune des 3 vidéos, va dans les réglages → Confidentialité → « Où cette vidéo peut-elle être intégrée ? » et choisis « Partout » (ou ajoute ton adresse github.io). Sinon la vidéo ne se lancera pas dans la page.

Plaquette page par page : le fichier `plaquette.html` (avec le dossier `pages`) affiche les 7 pages une par une, on glisse sur le côté pour passer à la suivante. Une fois en ligne, son adresse est `https://TON-PSEUDO.github.io/kurt-weddings/plaquette.html` : c'est ce lien-là à envoyer sur WhatsApp.
